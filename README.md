# Bienestar subjetivo y comportamiento político en Latinoamérica

Un mapa general de las hipótesis puede verse [acá](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/Comparativa%20de%20Hip%C3%B3tesis.xlsx). 

En general el trabajo actualmente cuenta con tres etapas: 
- Una prueba de las hipótesis con datos multinivel (individual de Latinobarómetro y nacional de V-Dem). Eso puede verse [acá](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/V-Dem.ipynb).
- Un conjunto de tests de Granger con agregación a nivel país. Eso puede verse [acá](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/Granger%20Test.ipynb).
- Un conjunto de Event Studies:
  - Con eventos seleccionados de manera no algorítmica. Eso puede verse [acá](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/Event_Studies.ipynb).
  - Luego se tomó la base del IFES conservando los eventos que coinciden con las ventanas de Latinobarómetro. Eso puede verse [acá](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/Event_Studies_II.ipynb).
  - Después se hicieron dos pruebas distintas generando la base de eventos con LLMs. Eso puede verse [acá](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/Event_Studies_III.ipynb) y [acá](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/Event_Studies_III%20B.ipynb).
  - Por último, se tomó la base de protestas de ACLED, conservando los eventos coincidentes. Eso puede verse [acá](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/Event_Studies_IV.ipynb).
