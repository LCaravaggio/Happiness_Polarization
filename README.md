# Bienestar subjetivo y comportamiento político en Latinoamérica

Actualmente el trabajo solo considera un modelo de Event Studys. 

Sobre Latinobarómetro: [EDA y descriptiva](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/Datos.ipynb)</br>

La identificación de los eventos se hizo: </br>
[Con la base de elecciones de IFES](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/IFES.ipynb)</br>
[Con la base de protestas ACLED](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/Protestas_ACLED.ipynb)</br>
[Con un LLM](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/Events_LLM.ipynb)</br>

Se evaluó el nivel de polarización de los eventos con la base de [GDELT](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/GDELT.ipynb).</br>

Sobre eso se corrieron un modelo estático y un modelo dinámico: </br>
[sin controles](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/Event_Studies_Pool.ipynb)</br>
[con controles](https://github.com/LCaravaggio/Happiness_Polarization/blob/main/Event_Studies_Pool_Controles_y_FE.ipynb)</br>
